# Как правильно настраивать порталы

Эта инструкция объясняет, как создавать стабильные и бесшовные переходы между комнатами в JSON-файлах. Правильная настройка гарантирует, что игрок не застрянет в стенах или в цикле телепортации.

## Анатомия портала

Каждый портал в массиве `"portals"` в файле комнаты — это объект со следующими ключевыми параметрами:

```json
{
  "id": "P_to_B",
  "wall": "east",
  "rect": { "center": [0.0, 1.1], "size": [1.6, 2.2] },
  "locked": false,
  "toRoomFile": "/rooms/RoomB.json",
  "exitPos": [11, 1.4, 0],
  "exitYaw": 90
}
```

### Разбор параметров:

-   `id` — Уникальное имя портала (например, `P_from_A_to_B`).
-   `wall` — На какой стене комнаты находится портал. Возможные значения: `"north"`, `"south"`, `"east"`, `"west"`.
-   `rect` — Размеры и положение портала на стене.
    -   `center`: `[смещение, высота]` — Центр портала. **Важно:** `смещение` идёт вдоль стены (по оси X для северной/южной стены и по оси Z для восточной/западной). `0.0` означает центр стены.
    -   `size`: `[ширина, высота]` — Видимые размеры портала.
-   `locked` — `true`, если портал заперт, иначе `false`.
-   `toRoomFile` — Путь к JSON-файлу комнаты, в которую ведёт этот портал.

### ✨ Ключевые параметры для бесшовности ✨

Эти два поля — самый важный секрет плавного перехода.

-   `exitPos`: `[x, y, z]`
    **Это — точные мировые координаты, где игрок появится после телепортации.** Координаты указываются для *целевой* комнаты.

-   `exitYaw`: `угол`
    **Это — угол поворота камеры игрока (в градусах) сразу после телепортации.** Позволяет направить взгляд игрока в нужную сторону.
    -   `0` — смотрит на север (+Z)
    -   `90` — смотрит на восток (+X)
    -   `-90` — смотрит на запад (-X)
    -   `180` — смотрит на юг (-Z)

## Главное правило: как избежать "петли телепортации"

**Проблема:** Игрок телепортируется и сразу же телепортируется обратно, застревая в цикле.

**Причина:** Координаты `exitPos` расположены слишком близко к обратному порталу в новой комнате. Игрок появляется уже внутри триггера обратного портала.

**Решение:** Всегда устанавливайте `exitPos` на безопасном расстоянии от портала (хотя бы на 1-1.5 метра вглубь комнаты).



На этой схеме `exitPos` для портала `A->B` находится в комнате `B`, но *за пределами* триггер-зоны портала `B->A`. Это даёт игроку возможность осмотреться после телепортации, не активировав переход обратно.
